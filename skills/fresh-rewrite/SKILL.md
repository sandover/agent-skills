# Fresh rewrite

Build the document around the reader's needs and the intended outcome. Drafting
before revisiting the original helps you choose a structure without inheriting
its organization or phrasing.

Set the original aside. Write a fresh bullet outline in a scratchpad and draft
from it without consulting the original. Once the new draft exists, review the
original for facts, qualifications, and useful material worth carrying over.
Adapt that material to the new structure and language. Replace the original
with the finished version and discard the scratchpad.

Use concrete, ordinary, declarative language. For technical material, help the
reader form an accurate mental model: use consistent terms, define unfamiliar
ones, make references explicit, and keep sentence structure simple. Use jargon
when ordinary language would lose precision.
