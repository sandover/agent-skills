# Be ambitious

Strengthen the approach to a task while preserving its goal, deliverable,
audience, and practical limits. Choose improvements that raise the quality of
the requested work without adding projects, features, or deliverables.

Use four questions to find the improvements that matter for this task:

1. What would a top professional do here that the user hasn't asked for?
2. What is the rawest useful source material they would start from?
3. Which specific methods and tools would they use?
4. What independent evidence or qualified review would show the result is right?

Give a brief, concrete answer to each, then use the answers to write a
self-contained replacement prompt. Name sources, methods, and checks precisely
enough to guide action. Prefer primary evidence when it helps.

Keep the prompt honest about available inputs: distinguish proposed resources
from inspected ones, name essential missing inputs, and reserve claims of
verification for checks that have passed. Choose checks that suit the field.

Return the four answers followed by the prompt. Execute the underlying task
only when the user also requests execution.

Based on the “Be ambitious” skill from Attention Heads, adapted from a prompt
shared by Felix Rieseberg (Anthropic), as shown in the user's reference.
